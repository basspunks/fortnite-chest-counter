# content.json

Treasure hunt data: weeks and their prizes (with the prize ids found in replays), odds and Treasure Hours.

Taken from [LED-N/Fortnite-ChestCounter](https://github.com/LED-N/Fortnite-ChestCounter/tree/main/content)
(MIT license, see `../replay-reader/LICENSE-Fortnite-ChestCounter`). The app ships this copy and, at start,
downloads the newest one from that repository (kept in the app's data folder), so new weeks show up without
a new version.
