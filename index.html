Chest Counter

How it works

During matches the counter looks at the small area right of the crosshair, five times a second, for the "+600 XP / CHEST" text. Nothing is recorded or sent: each look is dropped at once. Needs Windowed Fullscreen and the game in English (other languages later).

How it works

A closed chest hums; when it opens, the hum stops and a short burst plays. Only Fortnite's own sound is heard, never Discord, music or anything else on your PC. A chest the screen already counted is not counted again.

ReplaysThe exact count after each match

Needs Record Replays on in Fortnite (Settings → Game → Replays). FPS drops? Turn it off: the live count works without it.

Startup

More

Starts with Windows, hidden next to the clock, and shows the counter only while Fortnite runs. It hides a minute after the game closes, once the last replay is read. × on the bar only hides it; "Quit completely" (the icon next to the clock) stops it until you open it again.

OBS / streaming

The same numbers on a transparent page. In OBS: Sources → + → Browser → tick "Local file" → pick this file, width 420, height 110.

Chests from before

Add the chests you opened before the counter (a negative number removes some). Or type the matches shown in Fortnite → Career → Stats: the matches it has not seen count at your average. A new estimate replaces the old one.
